02 — The Detection Layer

Nine Checks Mapped to Ambulance Billing Errors

UPCODE · HCPCS A0-series

Basic life support (BLS) transport billed at an advanced life support (ALS) rate.

MILEAGE · A0425 units

Loaded miles billed exceed the actual point-to-point distance to the hospital.

LOS · Run report vs. bill

Level of service not supported by what the Patient Care Report (PCR) documents.

SUPPLIES · Supply line items

Items billed separately that are already bundled into the base transport rate.

GEO · ZIP designation

Rural or super-rural mileage bonus improperly applied to an urban trip.

MODIFIER · Modifier pairs

Origin/destination modifier used to bypass a payer coverage edit.

DUPLICATE · Claim lines

The same transport billed twice across primary/secondary statements.

INVALID · HCPCS

Code billed doesn't exist or doesn't apply to ground ambulance transport.

DOC-GAP · Records request

No run report on file to substantiate the billed level of care.
